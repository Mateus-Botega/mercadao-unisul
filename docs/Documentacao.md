## **PROJETO: SISTEMA DE LISTA DE COMPRAS DE SUPERMERCADO** 

## **1. ENUNCIADO** 

O sistema deverá permitir cadastrar produtos, consultar e localizar itens, registrar compras totais ou parciais e apresentar informações sobre os produtos adquiridos e pendentes, incluindo os valores estimados e gastos. 

A solução deverá utilizar estruturas de dados adequadas aos requisitos do problema. Cada equipe deverá descrever e justificar as estruturas escolhidas, explicando como elas contribuem para o funcionamento do sistema. 

A entrega deverá incluir o sistema desenvolvido e sua apresentação, com demonstração do funcionamento e explicação das decisões tomadas pela equipe. 

## **2. OBJETIVOS** 

- Aplicar os conceitos de estruturas de dados.

- Escolher estruturas de dados coerentes com os requisitos do problema. 

- Implementar operações de cadastro, consulta e atualização dos produtos. 

- Controlar compras totais e parciais e calcular valores estimados e gastos. 

- Explicar e justificar as decisões técnicas adotadas. 

## **3. REGRAS DE DESENVOLVIMENTO** 

- O sistema deverá gerenciar uma única lista de compras durante sua execução. 

- Os dados deverão permanecer apenas em memória durante a execução do sistema, sem persistência em arquivos ou banco de dados. 

- A equipe deverá escolher as estruturas de dados (exceto vetor e matriz), sem obrigatoriedade de adotar uma estrutura específica. 

- A equipe deverá entregar uma descrição técnica das estruturas escolhidas e justificar sua adequação ao problema. 

- As funcionalidades implementadas deverão manter os dados e os cálculos consistentes. 

## **4. OBSERVAÇÕES** 

- Não é necessário implementar interface gráfica; uma interface de texto é suficiente, desde que permita demonstrar as funcionalidades. 

- Não é exigido histórico das operações realizadas. 

- A equipe poderá propor decisões de implementação adicionais, desde que sejam coerentes com o problema e devidamente explicadas.
